Cybersecurity glossary

Find plain-language explanations of common security terms.

Phishing

Deceptive messages that attempt to steal information or induce unsafe actions.

Smishing

Phishing through text messages.

Vishing

Phishing through voice calls.

Malware

Software designed to harm or misuse systems.

Ransomware

Malware that blocks access or encrypts files and demands payment.

MFA

Authentication using more than one factor.

Passkey

A cryptographic sign-in credential that can resist phishing.

Encryption

Transforming information so it is unreadable without the appropriate key.

Firewall

A control that filters network traffic.

VPN

An encrypted connection to a VPN endpoint; it does not guarantee anonymity.

Social engineering

Manipulating people into unsafe actions.

Data breach

Unauthorized access to or disclosure of data.

Patch

An update that fixes software defects or vulnerabilities.

Password manager

A tool for generating and storing unique passwords.

HTTPS

Encrypted transport between a browser and a site; not proof the site is trustworthy.

Backup

A separate copy of data for recovery.

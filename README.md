# ClickSavvy 2.0
Beginner-friendly cybersecurity education website, originally created by Kristin Pondexter. This redesign retains the original lessons and branding and adds interactive learning tools using HTML, CSS and vanilla JavaScript. AI-assisted redesign.

## Run locally
Open index.html in a browser, or run `python -m http.server 8000` in this directory and visit http://localhost:8000.

## Features
Threats 101, Protection 102, scam scenarios, fictional password length demo, browser-local safety checklist, five-question quiz, resource links and a clearly labeled feedback demo. No backend or account required. No real passwords should be entered. The checklist alone uses localStorage. Feedback is not transmitted. Original contact details removed pending confirmation.

## Deploy
Upload the contents of this directory to the root of a GitHub repository and enable Pages from the main branch, root directory. Preserve a backup of the original site. Review on desktop and mobile before replacing a live site.

## Testing
Check all navigation, each quiz/scam answer, restart, password display, checklist persistence and feedback validation. External resource links should be checked before release.

## Version 3.0
Adds six Academy lessons, an eight-habit self-assessment, six scam scenarios, searchable glossary, local achievement badges, dark mode and starter journal articles. Progress and theme are stored locally when available. No accounts or backend. Scores are educational, not security audits. Feedback remains a demo. Starter articles and new features were AI-assisted; review and test before publication.
